5. React Router

<Link to="/testimonial">Testimonials</Link>

Programmatic Navigation

import { useNavigate } from 'react-router-dom';

const navigate = useNavigate();

const handleLogin = () => {
  // perform auth logic...
  navigate('/dashboard');
};

Protected Route Redirect

import { Navigate } from 'react-router-dom';

if (!user) {
  return <Navigate to="/login" replace />;
}

10. routers

Yes, they are different because **`Link`** and **`BrowserRouter`** serve completely distinct purposes in `react-router-dom`:

* **`BrowserRouter`** is the top-level **router provider**. It listens to the browser's URL history, syncs it with your application state, and enables all routing functionality across your app.
* **`Link`** is an **element component**. It renders an HTML `` anchor tag that allows users to navigate to different URLs without triggering a full page reload.

---

### Key Differences Breakdown

| Import | Type | Main Purpose | Where to Use |
| --- | --- | --- | --- |
| `BrowserRouter` | Provider Wrapper | Tracks browser location/history and acts as the parent container for routing context. | Wrap high up in your app tree (usually once in `main.jsx` or `App.jsx`). |
| `Link` | UI Component | Renders clickable links (``) for user navigation. | Inside components (like `Header.jsx` or `Footer.jsx`) where links are displayed. |
| `Routes` | Layout Container | Groups individual `` definitions and picks the best matching route for the current URL. | Around `` components. |
| `Route` | Route Definition | Maps a URL `path` to a specific React `element` component. | Inside ``. |
